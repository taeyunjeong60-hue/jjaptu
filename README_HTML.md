# 짭투 HTML 인터페이스 실행 방법

이 버전은 Pygame 화면 대신 HTML/CSS/JavaScript 화면을 사용합니다. 게임은 자음·모음 단어 맞히기 방식입니다. `jjaptu_server.py`는 WebSocket 서버로 유지되고, `web_app.py`는 웹 페이지를 제공합니다.

## 1. 설치
```bash
python -m pip install -r requirements-web.txt
```

## 2. 서버 실행
터미널 1에서 프로젝트 폴더로 이동한 뒤 실행합니다.
```bash
python jjaptu_server.py
```

## 3. 웹 화면 실행
터미널 2에서 실행합니다.
```bash
python web_app.py
```
브라우저에서 `http://127.0.0.1:8000`을 엽니다.

## 같은 Wi-Fi의 다른 기기에서 접속
서버 컴퓨터의 사설 IP 주소를 확인한 뒤 다른 기기에서 `http://서버IP:8000`으로 접속합니다. 방화벽에서 TCP 8000 및 WebSocket TCP 65535 연결을 허용해야 할 수 있습니다. HTML은 접속한 주소의 호스트 이름을 사용해 `65535`번 WebSocket 포트에 연결합니다.

## 참고
- `build/web/index.html`, `style.css`, `app.js`가 웹 화면입니다.
- `image/`의 기존 배경 이미지를 `build/web/assets/`로 복사했습니다. 현재 화면은 CSS 기반 디자인이며 이 이미지들은 추후 배경으로 쉽게 적용할 수 있도록 포함했습니다.
- 방 생성, 방 목록, 방 코드 입장, 참가자 목록 업데이트, 방 나가기를 지원합니다. 실제 끝말잇기 턴/단어 검증/게임 시작 로직은 기존 서버에 없으므로 아직 구현되지 않았습니다.
- HTTPS로 배포하는 경우에는 WebSocket도 WSS로 제공되도록 프록시/TLS 설정이 필요합니다.


## 방 생성 라운드 설정

로비에서 `방 만들기`를 누르면 5, 10, 20라운드 중 선택할 수 있습니다. 선택한 값은 `makeroom,<라운드 수>` WebSocket 메시지로 Python 서버에 전달되고, 서버의 방 정보에 저장됩니다. 방 목록과 대기실에는 저장된 라운드 수가 표시되며, 모든 참가자는 같은 설정을 확인할 수 있습니다. 기존 클라이언트와의 호환을 위해 라운드 수가 없는 `makeroom` 요청은 기본값 10라운드로 처리합니다.


### 닉네임 중복 방지

현재 접속 중인 플레이어가 사용 중인 닉네임은 다시 사용할 수 없습니다. 영문 닉네임은 대소문자를 구분하지 않으며, 중복 입력 시 닉네임 입력 화면에 경고가 표시됩니다.

## 방 개수 제한 및 방장 설정

- 서버에서 동시에 생성할 수 있는 방은 최대 100개입니다. 100개가 되면 새 방 생성 요청은 거절됩니다.
- 방 생성 시 총 라운드 수(5/10/20)와 최대 참가 인원(2/4/6/8/10명)을 선택할 수 있습니다.
- 대기실에서 방장에게만 `설정 변경` 버튼이 표시됩니다. 방장은 라운드 수와 최대 참가 인원을 바꿀 수 있고, 변경 내용은 참가자에게 실시간으로 전달됩니다.
- 최대 참가 인원은 현재 참가자 수보다 낮게 설정할 수 없으며, 정원이 찬 방에는 새 플레이어가 입장할 수 없습니다.


## 내부 게임: 자음·모음 단어 맞히기

1. 대기실에서 방장이 `게임 시작`을 누르면 설정된 라운드 수만큼 진행합니다.
2. 매 라운드마다 자음 1개와 모음 1개가 표시됩니다. 두 조건이 모두 들어 있는 한글 단어를 가장 먼저 제출하면 점수를 얻습니다.
3. 점수는 `기본 10점 + 단어 글자 수(최대 10점)`이며, 라운드마다 제한 시간은 30초입니다. 먼저 정답을 제출하면 다음 라운드로 넘어갑니다.
4. 국립국어원 표준국어대사전 검증을 사용하려면 `.env.example`을 참고해 프로젝트 폴더에 `.env` 파일을 만들고 `KOREAN_DICT_API_KEY`에 발급받은 API 키를 설정하세요. 서버가 `.env` 파일을 자동으로 읽습니다.
5. API 키가 없으면 데모 모드로 실행되며, 자음·모음 조건만 검사하므로 실제 사전 등재 여부는 보장하지 않습니다.
6. 추가 의존성 설치: `python -m pip install -r requirements-web.txt`


## 국어사전 API 키 설정

프로젝트 폴더의 `.env` 파일을 열고 `KOREAN_DICT_API_KEY=`의 `=` 오른쪽에 발급받은 표준국어대사전 API 키를 입력하세요.

```env
KOREAN_DICT_API_KEY=여기에_발급받은_API_키
```

키를 입력한 뒤 WebSocket 서버(`jjaptu_server.py`)를 재시작하면 적용됩니다. 실제 API 키를 채팅으로 보낼 필요는 없습니다. `.env` 파일은 공개 저장소에 올리지 마세요.
